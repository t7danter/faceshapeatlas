# FaceShapeAtlas

Independent, static, free site. Keep image processing and analysis assets on-device and same-origin, respectively. GA4 may measure visits on the production domain after consent. Never send photos, filenames, results, or measurements to analytics. No backend, paid APIs, accounts or image persistence. Keep heuristic scores distinct from probabilities. Never infer sensitive traits. Run `npm run validate` after meaningful changes. Do not stage, commit, deploy, create a Cloudflare project or bind a domain without explicit user instruction. Do not modify sibling projects.
